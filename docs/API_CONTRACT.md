# API CONTRACT — Clinova Healthcare REST API

> Generated by Phase 0 audit. Every endpoint listed below corresponds to a frontend page's data needs.  
> Base URL: `http://127.0.0.1:8000/api`  
> Auth: JWT Bearer token (except login).  
> All responses: JSON. Errors: `{ "detail": "...", "code": "..." }`.  
> Pagination: `{ "count", "next", "previous", "results" }` on list endpoints. Default page size: 20.

### Staff <-> Doctor ID Bridge
- **Frontend Contract**: The frontend passes and expects `doctorId` matching the `staff.id` (e.g. `staff-doc-01`).
- **Backend Model Structure**: In the DB, `cms_doctorapp.Doctor` has its own primary key `doctor_id` (e.g. `doc-001`) and a OneToOneField/ForeignKey `staff` referencing `cms_backendapp.Staff` (`staff_id` e.g. `staff-doc-01`).
- **API Resolution**:
  - All external API endpoints accepting `doctor` / `doctorId` (e.g., booking appointments, filtering prescriptions, lab orders, doctor dashboard) accept `staff_id` (or translate transparently).
  - Serializers expose `doctorId` pointing to `staff.staff_id` and `doctorName` pointing to `staff.first_name + ' ' + staff.last_name`.
  - Lookups internally perform: `Doctor.objects.get(staff__staff_id=doctorId)` or `Doctor.objects.filter(staff_id=doctorId)`.

### Money Representation Convention
- **API Contract**: All monetary amounts transmitted over the wire (e.g., `consultationFee`, `subtotal`, `taxAmount`, `discountAmount`, `totalAmount`, `paidAmount`, `balanceAmount`, `unitPrice`, `totalPrice`) are integer paise (`1 INR = 100 paise`).
- **Database Storage**: The MySQL database stores amounts as `DecimalField(max_digits=10, decimal_places=2)` in standard Rupee format (e.g., `500.00`).
- **Conversion Rule**: Conversions occur strictly within DRF serializers:
  - Inbound (request JSON -> DB model): `Decimal(val) / 100`
  - Outbound (DB model -> response JSON): `int(round(float(db_decimal) * 100))`

## Auth

| Method | Endpoint | Roles | Request | Response | Notes |
|--------|----------|-------|---------|----------|-------|
| POST | `/auth/login/` | Public | `{ username, password }` | `{ access, refresh, user: { id, username, role, staffId, staffName, avatarUrl } }` | Account lock after 5 failures (5 min). Inactive → 403. |
| POST | `/auth/refresh/` | Public | `{ refresh }` | `{ access }` | |
| GET | `/auth/me/` | Any | — | `{ id, username, role, staffId, staffName, avatarUrl, departmentId }` | |
| POST | `/auth/logout/` | Any | `{ refresh }` | 204 | Blacklist refresh token |

## Patients

| Method | Endpoint | Roles | Notes |
|--------|----------|-------|-------|
| GET | `/patients/` | RECEPTIONIST, DOCTOR, ADMIN | Search: `?search=` (name, MRN, phone). Filter: `?doctor_scope=mine`. Doctor-role requests are always restricted to patients assigned to or seen by that doctor. |
| GET | `/patients/{id}/` | RECEPTIONIST, DOCTOR, ADMIN | Detail with allergies, chronicConditions; Doctor access is restricted to assigned/seen patients. |

| POST | `/patients/precheck/` | RECEPTIONIST | Validate before payment (guardian, duplicates). Returns 200 or 400. |
| GET | `/patients/{id}/clinical-history/` | DOCTOR | Full longitudinal consultations, prescriptions, and lab-order history for an assigned/seen patient; access to the patient is Doctor-scoped, and history includes records from all clinicians. ## Appointments

| Method | Endpoint | Roles | Notes |
|--------|----------|-------|-------|
| GET | `/appointments/` | RECEPTIONIST, DOCTOR, ADMIN | Filter: `?date=&doctor=&patient=&status=`. Doctor-role requests are always restricted to the authenticated doctor's appointments. Paginated results expose `id`, `patientId`, `patientName`, `patientMrn`, `time`, `date`, and `status`. |
| GET | `/appointments/{id}/` | RECEPTIONIST, DOCTOR | Detail with patient name, doctor name, bill info; Doctor access is restricted to own appointments. |

| POST | `/appointments/book-and-pay/` | RECEPTIONIST | Book + collect consultation fee. Body: `{ patientId, doctorId, mode, date?, time?, type?, reason?, payment: { method } }`. Returns `{ appointment, bill }` |
| POST | `/appointments/{id}/cancel/` | RECEPTIONIST | Body: `{ reason, refund? }`. Cancels bill if applicable. |
| POST | `/appointments/{id}/check-in/` | RECEPTIONIST | Validates: same day, fee paid |
| POST | `/appointments/{id}/no-show/` | RECEPTIONIST | Only after grace period |
| POST | `/appointments/{id}/update-status/` | RECEPTIONIST, DOCTOR | Body: `{ status }` |
| GET | `/appointments/slot-board/` | RECEPTIONIST | `?doctor=&date=`. Returns slot grid with free/booked/past states |
| GET | `/appointments/next-walkin-slot/` | RECEPTIONIST | `?doctor=`. Returns the next available walk-in slot |
| GET | `/appointments/consultation-fee/` | RECEPTIONIST | `?doctor=`. Returns fee in paise |
